# Getting started

Smart Bookmark Manager is a place to save links, group them into **collections**, label them with **tags**, and add **notes** so you can find them later.

## Open the app

If someone already runs the app for you, use the URL they gave you.

If you run it on your own computer:

1. Make sure the project is installed (`npm install` once).
2. In a terminal, from the project folder, run:

```bash
npm run dev
```

3. In your browser, open [http://localhost:3000](http://localhost:3000).

You should see a sign-in screen. If the page does not load, the app is not running — start `npm run dev` again and wait until it says it is ready.

## First visit

1. Create an account or sign in ([Sign in](sign-in.md)).
2. You land in your **workspace**. An **Inbox** collection is created for you automatically.
3. Save a link from the workspace or from the [browser extension](browser-extension.md).

## What you need

- A modern browser (Chrome, Edge, Brave, or Firefox for the website)
- For the extension: Chrome, Edge, or Brave (not Firefox in this version)
- An email address, or a Google account if Google sign-in is turned on
